        Release Automation
        
Four-Stage Build & Release Pipeline

        

          How make build compiles, strips, and audits the distribution package to guarantee zero source leaks.
        

      


      


        
        

          

            1
            scripts/keygen.py
          

          
Ed25519 Key Generation

          

            Generates 256-bit asymmetric keypair into .secrets/. The private key remains vendor-side only.
          

          

            make keygen
            
          

        


        
        

          

            2
            build_release.sh
          

          
Public Key Baking

          

            Injects public.pem directly into license_guard.py right before Cython native C compilation.
          

          

            make build
            
          

        


        
        

          

            3
            Strict Audit
          

          
Source & C Strip Audit

          

            Deletes all .py, .c, .map, and .pem files inside core_engine/. Fails build if found.
          

          

            make test
            
          

        


        
        

          

            4
            dist/client_release
          

          
Host-Locked Release

          

            Signs a valid 30-day host-bound license.key and packages the complete runnable client release.
          

          

            make run
